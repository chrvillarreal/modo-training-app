# Modo Training — Coach App

Prototipo funcional aprobado para entrenadores personales.

## Alcance actual
- Landing comercial
- Dashboard
- Alumnos
- Rutinas
- Biblioteca de ejercicios
- Calendario
- Adherencia
- Progreso
- RIR / seguimiento de carga
- Responsive móvil/escritorio

## Principio de producto
**Tu criterio. Tus rutinas. Menos vueltas.**

Flujo central:
`crear → duplicar → personalizar → ejecutar/registrar → revisar → ajustar`

## Separación de proyectos
Este repositorio NO incluye RM Formación / Curso ARM, la biblioteca R2 del curso ARM ni la app de Nutrición Deportiva.

## Vercel
Este prototipo no requiere build. Framework Preset: Other; Build Command vacío; Output Directory `.`; Root Directory `.`.

## Estado
V1 = prototipo front-end navegable con datos demo. No es todavía una plataforma multiusuario con persistencia real.

## Próxima arquitectura
Autenticación profesor/alumno, base de datos, RLS/autorización, alumnos persistentes, rutinas y plantillas persistentes, sesiones, historial/snapshots, progreso, storage privado y panel alumno.
