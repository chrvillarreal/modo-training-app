# Deploy rápido

## GitHub
Este repositorio es independiente de `rm-training`.

## Vercel
1. Add New → Project.
2. Import Git Repository.
3. Seleccionar `modo-training-app`.
4. Framework Preset → Other.
5. Build Command → dejar vacío.
6. Output Directory → `.`.
7. Deploy.
